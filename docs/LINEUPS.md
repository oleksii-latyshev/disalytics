# Personal lineups

The Lineups dock shows saved throws on each map. On desktop, map and utility filters sit to the left of the radar, and the throw list sits to the right. The radar fits the available viewport height. **View** opens throw details and grouped variants without moving points. Zoom with the wheel or the map controls; drag to pan while zoomed. A numbered marker opens the throws saved near the same origin.

## From a match

The match's lineups view finds a lineup by where it landed. Throws taken on the move are only dots (switch **Throws on the move** on to see them): they cannot be repeated from a spot. The rest are grouped into variants (same kind, thrown from within 110 units of each other and landing within 150) and variants into targets (same kind, landing within 200 units), and a marker stands for each target. Pick one to see numbered origins with an arc to the landing, how to repeat each, and chips that open the replay at the throw. **Save lineup** stores it with its title, side and command filled in; saving the same variant of a match again replaces it, and **Undo** removes it. A name with a leading ≈ means the landing lies near a callout rather than inside it.

Switch to **Edit** to create, import, move, or merge throws. Click **Create lineup**, mark the throw position and landing point, then enter a title, grenade kind, movement instructions, and optional media. Click nodes to add them to the selection; selecting another keeps previous nodes highlighted. Selected throw positions use a diamond outline, landings a circle, and bounces a square, with the throw title and point type shown above the radar. Shift, Ctrl, or Cmd-click toggles a node. Click empty space or use **Clear selection** to reset. Drag a node to save its new position; moving a shared group point updates every member of that group. Select origins from multiple throws to merge origins, or landings to merge landings; mixed point types cannot be merged. List checkboxes select whole throws for group actions and can also clear a throw’s selected nodes.

The form keeps coordinates, view angles, and the `setpos` command under **Coordinates and console details**. Throws saved from a demo retain their captured `setpos` command and can be edited here.

Photo links and video or guide links are separate. Select one or more photos to convert each to WebP locally: a circle around the crosshair (100 pixels across at 1080p, larger on taller screenshots) keeps its original pixels, and the rest is softened to the detail of a 1600-pixel copy so the file stays small. Photos you select are stored on this device when you save the lineup, so a personal lineup needs no host and works offline. To get a shareable link instead, press **Upload manually** on a prepared photo: the browser sends the converted file directly to Catbox and opens its response in a new tab. Copy the returned URL into the photo link field and press **Add link**; Catbox does not permit the app's browser script to read the cross-origin upload response. No demo file is sent to Catbox.

Export produces a version-2 JSON file with the lineup data, media URLs and the locally stored photos as base64 data URLs keyed by their SHA-256, so the file is self-contained. Import accepts version-1 and version-2 files, verifies each photo against its hash, and rejects a file whose lineup references a photo it does not carry. A locally stored photo appears in a lineup as `local:<sha-256>`; other photo URLs must use HTTP or HTTPS. Photos no stored lineup references are deleted. External media needs a network connection; the rest of the lineup remains available offline.
